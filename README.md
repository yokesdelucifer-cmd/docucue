# DocuCue

**Staff certificate and licence expiry tracking for UK businesses.**

DocuCue helps businesses keep employee and contractor certificates, qualifications, licences, expiry dates and supporting documents organised in one place.

## What DocuCue does

- Tracks staff and contractor certificates and licences
- Shows valid, due-soon and expired records
- Keeps supporting documents attached to the relevant worker record
- Uses AI-assisted extraction to suggest certificate details for review
- Sends expiry reminders based on configured reminder windows
